# 芒格多元思维模型标签

建立跨学科思维模型格栅。按知识背后的底层规律分类，不按文章表面主题分类。

## 输出格式

在 YAML 的现有 `tags` 属性中输出：

```yaml
tags: [心智模型/微观经济学, 心智模型/复杂系统与决策科学]
```

选择 1–5 个标签，通常 1–3 个足够。按“最底层原因 → 最核心模型 → 最有迁移价值的学科”排序。不要为了显得丰富强行添加。

## 规范标签表

| 标签 | 判断重点 | 典型模型 |
| --- | --- | --- |
| `心智模型/元认知与思维方法论` | 如何思考、学习、判断与升级认知 | 第一性原理、逆向思考、能力圈、决策框架 |
| `心智模型/数学与统计学` | 概率、数量关系、数据和预测 | 贝叶斯、期望值、复利、大数定律、回归均值 |
| `心智模型/心理学` | 人的行为、动机、情绪和认知偏差 | 损失厌恶、从众、权威效应、习惯形成 |
| `心智模型/复杂系统与决策科学` | 系统运行、反馈、长期变化与决策 | 涌现、杠杆点、非线性、网络效应、动态平衡 |
| `心智模型/工程学` | 如何设计可靠、可维护的系统 | 模块化、自动化、抽象、冗余、流程优化 |
| `心智模型/微观经济学` | 稀缺资源、激励、价格、选择和成本 | 供需、机会成本、边际效应、交易成本、竞争 |
| `心智模型/管理学与商业` | 如何组织资源并创造商业价值 | 商业模式、护城河、产品生命周期、战略 |
| `心智模型/投资学与金融学` | 财富配置、风险与收益 | 价值投资、资产配置、市场先生、安全边际 |
| `心智模型/投资原则与品格` | 支撑长期正确决策的行为品质 | 耐心、克制、诚信、独立思考、避免愚蠢 |
| `心智模型/会计学` | 企业经营结果和真实价值的记录 | 资产负债表、利润表、现金流、财务指标 |
| `心智模型/生物学与进化论` | 生命、适应、选择和生态关系 | 自然选择、生态位、适者生存、进化反馈 |
| `心智模型/物理学与化学` | 物质、能量、约束和自然规律 | 杠杆、熵、临界点、相变、第一性原理 |
| `心智模型/历史学` | 长周期、兴衰和重复出现的模式 | 周期、路径依赖、历史经验 |
| `心智模型/哲学` | 意义、道德、价值观和世界观 | 价值判断、人生意义、伦理原则 |
| `心智模型/法学与政治学` | 制度、权力、规则、合约和治理 | 法律、制度设计、组织治理、权责边界 |

## 判断流程

### Step 1：提取机制

通读整张卡片，提取：

- 核心观点；
- 关键机制；
- 主要因果关系；
- 可迁移的应用领域。

不要只扫描标题或关键词。

### Step 2：判断底层问题

- 如何思考、学习或判断？→ 元认知与思维方法论。
- 如何预测数量、概率或变化？→ 数学与统计学。
- 如何理解人的行为？→ 心理学。
- 如何理解反馈、相互作用和长期结果？→ 复杂系统与决策科学。
- 如何设计可靠流程或系统？→ 工程学。
- 如何配置稀缺资源和激励？→ 微观经济学。
- 如何创造商业价值或组织执行？→ 管理学与商业。
- 如何配置财富与管理风险？→ 投资学与金融学。
- 如何保持长期正确行为？→ 投资原则与品格。
- 如何理解企业报表？→ 会计学。
- 如何理解适应、选择与生态？→ 生物学与进化论。
- 如何理解能量、约束和自然机制？→ 物理学与化学。
- 如何理解周期和长期历史规律？→ 历史学。
- 如何做价值和意义判断？→ 哲学。
- 如何理解制度、权力和治理？→ 法学与政治学。

### Step 3：筛选与排序

1. 删除只与表面主题相关、无法解释底层机制的标签。
2. 合并重复视角；相邻学科只有在分别解释不同机制时才同时保留。
3. 至少保留 1 个，最多保留 5 个。
4. 按底层解释力和迁移价值排序。

## 更新已有笔记

- 只打标时，读取完整正文后修改 YAML 的 `tags`，不改变正文。
- 已有 `tags` 时重新评估心智模型部分、规范化拼写并去重，同时保留其他已有标签。
- 不新增 `mental_models` 或其他平行属性。
- 不创建标签表之外的新学科名称；确实无法归类时不强行添加，并说明原因。

## 示例

“机会成本”的底层机制是稀缺资源下的取舍，主要标签为：

```yaml
tags: [心智模型/微观经济学, 心智模型/复杂系统与决策科学]
```
