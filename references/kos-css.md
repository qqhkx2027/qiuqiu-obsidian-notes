# KOS CSS

用于生成或更新 Vault 根目录的 `kos.css`，为知识操作系统（KOS）提供统一的视觉层。

## 工作流

1. 检查 Vault 根目录是否已有 `kos.css`、其他 CSS snippets，以及 `.obsidian/appearance.json` 的启用情况。
2. 根据首页、常青卡片和目录结构提出样式提案。
3. 输出完整 CSS 或精确 diff，标明会影响的选择器。
4. 用户确认后才创建或更新 `kos.css`；不得静默覆盖已有样式。

## 默认视觉方向

- 清晰的层级、适度留白、低饱和强调色。
- 优先使用 Obsidian CSS 变量，避免固定颜色破坏主题适配。
- 覆盖范围默认包括：首页导航卡片、Callout、标签、表格、标题层级和窄屏阅读。
- 复杂组件使用明确的 `.kos-*` 前缀，避免污染主题或插件样式。

## 安全规则

- 不修改第三方主题文件；只写 Vault 根目录 `kos.css` 或用户指定 snippet。
- 不删除已有规则；冲突时新增更具体的 `.kos-*` 选择器并说明优先级。
- CSS 写入后检查括号闭合、变量回退和暗色/亮色模式。
- 写入后提醒用户在 Obsidian 的 CSS snippets 设置中启用该文件（若尚未启用）。
