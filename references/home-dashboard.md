# 首页工作台

用于生成 Obsidian 的首页（Home / Dashboard）。首页是导航层，不是知识正文仓库。

## 工作流

1. 扫描 Vault 的一级目录、索引页、常用标签和最近更新笔记。
2. 归纳入口：项目、领域、资源、常青卡片、归档、Agents 和收件箱。
3. 先输出首页 Markdown 预览，说明每个入口的真实目标。
4. 用户确认后才写入；默认路径为 Vault 根目录 `00-Home.md`，已有同名文件时先展示差异。

## 页面结构

- 顶部：一句话定位、今日焦点或待处理入口。
- 核心导航：只链接到真实存在的文件夹、索引页或用户明确指定的文件。
- 工作区：Projects、Areas、Resources、Archives、Agents。
- 知识入口：Evergreen、LLM-WiKi、收件箱或用户已有索引。
- 最近更新：仅在 Vault 已有可靠 Dataview/查询能力时生成查询；否则使用静态链接，避免写入无法运行的代码。

## 规则

- 不凭空创建不存在的 `[[链接]]`，不为了好看批量生成空文件。
- 保留用户已有首页的内容、链接和个性化区块。
- 首页保持短小，复杂内容放入各目录的索引页。
- 使用 Obsidian 原生 Markdown；Dataview、Buttons 等插件语法必须先确认插件可用。
- 写入前列出新增、更新和保留的区块。
